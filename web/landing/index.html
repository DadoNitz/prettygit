From profile to PDF.

First, it reads your public profile.

npx --package=github:DadoNitz/prettygit prettygit fetch USER
out/DadoNitz/profile.json

No login needed. Sign in with gh or set GITHUB_TOKEN for a higher rate limit.

Then it writes the README.

npx --package=github:DadoNitz/prettygit prettygit readme USER --style noir
out/DadoNitz/README.noir.md
out/DadoNitz/assets/noir-banner.svg
out/DadoNitz/assets/noir-terminal.svg

The two noir SVGs go next to README.md in your USER/USER repository.

And it prints the résumé.

npx --package=github:DadoNitz/prettygit prettygit resume USER --style aesthetic --lang en
out/DadoNitz/resume-aesthetic.html
out/DadoNitz/resume-aesthetic.pdf

Saved as HTML and PDF. The PDF comes from the Chrome, Edge or Chromium already on your machine.

Optional AI, with your own key.

Paste an Anthropic API key in the app and Claude rewrites your copy. It works only from the facts in your GitHub.

What Claude writes

  • A short headline
  • A three-word motto
  • Your intro
  • The about-me bullets
  • A closing line
  • The résumé summary
  • Which repos to feature

What it never does

  • Invent jobs, degrees, numbers or skills
  • Follow instructions found inside your repos
  • Publish anything for you

At home in your terminal.

The same styles run as a Node CLI with zero dependencies, and as a Claude Code plugin with an agent and five skills.

Run it with npx, or clone it

No npm install either way. Node 20 or newer, and everything lands in out/USER/.

npx --package=github:DadoNitz/prettygit prettygit readme USER --style noir
git clone https://github.com/DadoNitz/prettygit.git
cd prettygit
node bin/prettygit.mjs resume USER --style direct --lang en

A polish bot that asks first
